# SEN66 display fonts

`DisplayFonts.h` contains proportional, monochrome U8g2 fonts generated from
Adobe Helvetica BDF sources. Every size is rasterized at its native resolution;
the dashboard does not enlarge the default Adafruit bitmap font. The primary
temperature, humidity and CO₂ readings use the bundled numeric U8g2 font
`u8g2_font_logisoso34_tn`, rendered at its native 34-pixel height. This condensed
face fits even −60.0, 100.0 and 10000 without reducing their size. Decimal commas
are used on screen. A Helvetica en dash is used for unavailable readings because
the numeric font does not include that Unicode character.

| Face | Use |
|---|---|
| Logisoso 34 (bundled in U8g2) | Main temperature/humidity/CO₂ values |
| helvB24 | Main unavailable-value placeholder |
| helvB18 | System screen titles |
| helvB14 | PM/VOC/NOx values and system messages |
| helvB08 | Labels and quality descriptions |
| helvR08 | Status, units and system screen details |

Included code points: ASCII 32–126, Latin 160–383 (including Czech), en dash
U+2013 and subscript two U+2082. UTF-8 decoding is provided by
`U8g2_for_Adafruit_GFX` 1.8.0. Arbitrary scripts outside this subset are not
supported; this does not change the separate legacy MQTT text API.

The generated header is checked in, so ordinary PlatformIO builds need neither
network font downloads nor a font converter. To regenerate on Windows:

```sh
python scripts/generate_display_fonts.py
```

On other platforms, first build upstream `bdfconv`, then run:

```sh
python scripts/generate_display_fonts.py --converter /path/to/bdfconv
```

The script downloads BDFs and the optional Windows converter from the pinned
U8g2 revision `d6c8499c5f2707cac8eccd09fd8f677d12b17977`. Downloaded tools stay
in ignored `.pio/display-fonts/`. The upstream notices and permission to
redistribute the generated font data are preserved in [LICENSE.txt](LICENSE.txt).

The Logisoso font is supplied directly by the pinned U8g2 library and is not
regenerated by this script. Its upstream attribution identifies Mathieu Gabiot
(Brussels, 2009); see the library's font notices. Host rendering tests extract
the same numeric font definition from the installed library for their previews.
